# Rares Macovei | Software Engineer & Game Designer

Source code for my personal portfolio website, hosted at [raresmac.github.io](https://raresmac.github.io).

I built this site using Blazor WebAssembly to showcase my software development, game design projects, and technical skills in an interactive visual layout.

## Tech Stack

- **Frontend:** Blazor WebAssembly (.NET 9)
- **UI Framework:** MudBlazor
- **Interactive UI:** Custom JavaScript LERP scroll wheel for smooth project navigation.

## Highlighted Projects

- **TypeScript:** *Segame* - Desktop game library tracker built with Electron, React, and TypeScript.
- **VR:** *Memento Vivere* - Virtual reality gameplay and comfort mechanics showcase.
- **C++:** *ReadsProfiler* library host and *Electronic Circuits* CAD editor.
- **Web Apps:** *Lools*, *FM26 Tactics*, and *BalatroHub*.
- **Machine Learning:** *LOL Predictor* - Match outcome prediction neural network.

## Deployment

Automated via GitHub Actions. Every push to `main` builds the Blazor application and deploys the static output to GitHub Pages.
